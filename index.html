⚙️ GitHub-synkronointi

Yhdistä GitHub-repoon, jotta varaukset synkronoituvat kaikkien laitteiden välillä.
Tämä asetus tehdään kerran per laite.

📋 Tarvitset Personal Access Tokenin

  1. Mene github.com/settings/tokens
  2. Klikkaa Generate new token (Fine-grained)
  3. Nimi: tyopiste-varaus, voimassaolo: 90 päivää
  4. Repository access → Only select repositories → valitse reposi
  5. Permissions → Contents: Read and write
  6. Generate → kopioi token alle ⬇️
